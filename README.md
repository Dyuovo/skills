### 📄 markitdown — 文档转 Markdown 工具

基于 Microsoft MarkItDown，支持 20+ 种文件格式批量转换为 LLM 可读的 Markdown：

**支持格式**：PDF（含 OCR）、DOCX、PPTX、XLSX/CSV、HTML、JSON、EPUB、图片（OCR）、音频（转写）等

**快速使用**：
```bash
python3 markitdown_tool.py input.pdf -o output.md
```

**首次安装**：
```bash
bash setup_markitdown.sh
```
